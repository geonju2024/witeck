# Data

`processed` 폴더에는 손 랜드마크에서 생성한 학습용 NPZ 파일이 있습니다.

## 최종 데이터

`witeck_g1_g24_mobile_v1.npz`가 최종 모델 학습과 평가에 사용하는 데이터입니다.

- 제스처 범위: G1부터 G24
- 입력 길이: 32 프레임
- 특징 차원: 127
- 특징 구성: 손 위치 63개, 속도 63개, 유효 프레임 정보 1개
- 상체 포즈: 사용하지 않음

`witeck_g1_g5_hand_only_v1.npz`는 기존 G1부터 G5까지의 기본 데이터입니다.

원본 영상에는 인물 정보가 포함될 수 있으므로 GitHub에 올리지 않고 팀 공유 드라이브에서 관리합니다.
